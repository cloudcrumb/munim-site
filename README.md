# munim-site

The public pages for **Munim**, a household accounts app for Indian homes.

- [Privacy Policy](https://cloudcrumb.github.io/munim-site/privacy.html) — the URL given to App Store Connect
- [Support](https://cloudcrumb.github.io/munim-site/support.html) — the support URL given to App Store Connect

Plain static HTML, no build step. Served by GitHub Pages from the root of `main`.
The source of truth lives in the app repo under `store/site/`.
